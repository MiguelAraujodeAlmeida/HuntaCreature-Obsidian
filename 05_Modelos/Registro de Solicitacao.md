# Modelo de registro de solicitação

Usar como nova seção no Histórico de Contexto, sem criar cópias da especificação.

## CTX-AAAA-MM-DD-NN — Título

- Pedido humano e decisões confirmadas:
- Resultado: implementado / somente proposta / bloqueado / parcialmente concluído.
- Regras substituídas e links para notas donas:
- Evidência: o que foi realmente observado; separar checks, Play, feedback e aprovação.
- Código: commit e identificação do lugar quando aplicável.
- Autoria/ambiente: IA ou pessoa, chat/dispositivo se conhecido; usar “não registrado” quando ausente.
- Pendências e próximo passo:
- Sincronização: Git registra commits; no relatório final confirmar remoto ou indicar pendência. Não escrever um SHA autorreferente.

Para bugs: passos, esperado, observado, versão, dispositivo e captura/Output.
